# 来源与许可证

YOLOv12 与 BoT-SORT 来自原移交项目 YOLOv12-BoT-SORT-ReID-main。本包保留上游 AGPL-3.0 许可证于 LICENSE-上游.txt 与 vendor/botsort/LICENSE，包含修改后的运行与跟踪源码。ONNX 与引擎由移交的 MOT_yolov12n.pt / COCO_multiclass/yolov12n.pt 导出，其来源权重哈希在模型元数据中。未声称重新训练过模型。

离线 wheel 为 Python 3.10 Linux aarch64 的 NumPy、SciPy、lap、Cython、cython_bbox、PyYAML、pycocotools；各自许可证保留在 wheel 内 *.dist-info/ 目录。GPU 库由系统 JetPack 提供。Chrome for Testing ARM64 浏览器的许可证与第三方声明保留在 browser/ 内。

MOT17/MOT20 视频是 MOTChallenge 网站公开的未画框预览，不是完整原尺寸 JPEG 数据集；VisDrone 三段验证 JPEG 转为 MP4，来源与镜像身份校验见 videos/README_素材选择.md 和下载清单。素材使用遵循相应数据集条款；本包不改变其授权。MOT20-08 没有公开 GT。UAV 例片为原移交项目自带的 MultiUAV-003.mp4。

reports/原工程FP32审计脚本_仅存档.py 用于记录原工程对照实验，不属于独立运行入口；重跑 FP32 原参考需原工程权重与 PyTorch。可在本包独立重跑 tools/benchmark_accuracy.py 的 TensorRT 对照。
